# Your learning workspace

Edit these files in your editor. Open the matching task in Learnspace to read them; the viewer checks for saved changes every five seconds while visible.

Start with the worked example: [CS12 — JOINs](cs-and-sql/CS12/README.md).

## Learning loop

1. Read the task goal and sources.
2. Explain the concept in theory/.
3. Keep your own reasoning and mistakes in notes/.
4. Write and run experiments in code/.
5. Save actual output, screenshots, and conclusions in results/.
6. Keep relevant links in resources/.
7. Record progress separately in the task UI after demonstrating the outcome.

Templates are prompts, not completed lessons or evidence. File presence never marks a task complete. Code is displayed, not executed by Learnspace. Start web projects separately and link their URL in resources/links.md.
