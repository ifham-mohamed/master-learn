# Your learning workspace

Edit these files in your editor. Open the matching task in Learnspace to read them; the viewer checks for saved changes every five seconds while visible.

Start with [JA05 — the first warehouse terminal task](java-and-spring/JA05/notes/00-warehouse-practice.md) and the [project requirements](../projects/warehouse-dispatch/README.md). Every task has a `notes/00-warehouse-practice.md` brief. Continue [CS12 — warehouse JOINs](cs-and-sql/CS12/notes/00-warehouse-practice.md) alongside the Java work.

## Learning loop

1. Recall one concept, then read the task brief and check the documentation.
2. Write and run your own code in `projects/warehouse-dispatch/`. Keep isolated experiments in the task's `code/` folder.
3. Record what you ran, what happened, and your next action. Use **Record result** in Learnspace or keep output in `results/` and link it from the task's evidence.

Templates are prompts, not completed lessons or evidence. File presence never marks a task complete. Code is displayed, not executed by Learnspace. Start web projects separately and link their URL in resources/links.md.
