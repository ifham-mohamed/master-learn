# Run the JOIN lab

Requires Python 3 with its standard-library SQLite support. No database server or additional package is needed.

From the repository root:

```sh
python learning/cs-and-sql/CS12/code/run_example.py
```

The script creates an in-memory database, runs five queries, checks exact expected rows, and writes `results/evidence.md` and `results/output.json`. Rerunning replaces those two generated files. Keep your personal reflections in `notes/`.

Open Results in this task to see the new output within five seconds. [Read the recorded evidence](../results/evidence.md).

`CustomerOrders.jsx` is an illustrative React component. The workspace displays its source. To run it, copy it into your separate React project, start that project, and add its local URL to a Markdown document in `results/`. Source files are never automatically executed by Learnspace.
