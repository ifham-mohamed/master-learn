# BE79 — Trade-off communication

Week 20 · Core · Warehouse checkpoint B20

## Review and learn

Trade-off communication, constraints and alternatives.

## Do the work

Explain one choice such as locks versus conditional updates, or session versus bearer authentication.

## Pass check

State the chosen approach, the cost accepted and a condition that would change your choice.

Write the implementation and checks yourself. Use documentation, the debugger and actual runs. Save what you ran, what happened, and your next action in [Results](../results/evidence.md) or record it in Learnspace. Include a commit or result path when useful.
