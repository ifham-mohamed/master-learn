# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The owner studies software engineering and records personal progress. Public visitors browse the curriculum. Desktop is the main coding environment; mobile and the installed web app must remain fully usable.

## Product Purpose

Support daily learning and coding, curriculum exploration, and weekly planning. Prioritize the current task, timer, next action, and deadlines on the dashboard.

## Operating Context

A 24-week curriculum with 236 tasks, theory, notes, source code, results, practice, resources, and reviews. Local learning files are edited in the codebase; GitHub Pages displays deployed snapshots.

## Capabilities and Constraints

Preserve Next.js static GitHub Pages deployment, device-local progress, optional reviewed Google Sheets sync, timers, offline access, installation, and backups. No additional hosting or database service. Preserve existing data and functionality.

## Product Principles

- Show key information first and reveal secondary details on demand.
- Group sidebar navigation into daily work, curriculum, and settings; use a drawer on mobile.
- Let the owner act and visitors browse without confusing public curriculum with personal progress.
- Use clear contrast, readable text, keyboard access, and reduced-motion support.

## Brand Commitments

Learnspace name retained. User approved a complete visual replacement and delegated color selection to fit the learning use case. Motion should be subtle during work, with an expressive theme transition respecting reduced-motion preferences.

## Evidence on Hand

Original workbook and HTML in sources/, normalized task records in src/data/, learning files in learning/. Existing task results are recorded data, not verified mastery.
